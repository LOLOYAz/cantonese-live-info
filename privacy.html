隐私政策

更新：2026年10月15日 · 开发预览版说明

应用尚未公开发行。此政策描述本项目的隐私设计与处理范围；正式版本发布前会按经过验证的实际行为更新。

麦克风与本地处理

麦克风仅用于你主动开始的现场听译。音频在设备内存中处理，用于识别粤语和生成文字翻译，不保存为录音文件，不发送至开发者或第三方推理服务。暂停、切到后台或锁屏后停止采集；恢复听译需要你手动操作。

文字记录

已确认的原文与译文自动保存在本机应用目录，直至你删除。你可以删除单条或全部记录，卸载应用也会移除应用内数据。历史库设置为不参与系统云备份。删除应用内记录不会删除你此前导出的副本。

你主动复制或导出的内容

复制会将文字放入系统剪贴板；导出会创建 TXT 文件并打开系统分享界面。你选择的其他应用或存储服务可能按其自身政策处理内容，请自行选择接收方。应用不能撤回已分享的副本。

账号、广告与诊断

应用无需账号，不接入广告、追踪或自动上传崩溃信息的 SDK。性能诊断只记录耗时、资源状态等指标，不记录录音或字幕正文。你主动反馈时，请勿提交他人的谈话、敏感资料或账号凭据。

模型与权限

模型随应用安装交付，日常听译无需运行时联网下载。应用请求麦克风权限；你可在系统设置中撤销。保持屏幕常亮只在你启用该功能且听译正在进行时生效。

本说明网站

网站由 GitHub Pages 托管，不放置分析脚本。GitHub 可能为安全目的记录访问者 IP 地址等访问日志，详见 GitHub 隐私声明。访问本网站不会将应用中的听译记录发送给 GitHub。
